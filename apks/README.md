# 📲 Guía rápida de instalación de la APK

1️⃣ **Descargar la APK**  
- Entra en la carpeta `apks/` del repositorio.  
- Pulsa sobre el archivo `.apk` (ejemplo: `miapp-v1.apk`).  
- Pulsa **Download** para bajarlo a tu móvil.

2️⃣ **Permitir instalación desde el navegador**  
- Ve a **Ajustes → Seguridad → Instalar apps desconocidas**.  
- Activa la opción para tu navegador (Chrome, Firefox, etc.).

3️⃣ **Instalar la APK**  
- Abre el archivo descargado (`miapp-v1.apk`).  
- Pulsa **Instalar**.  
- Espera unos segundos hasta que termine.

4️⃣ **Abrir la app**  
- Busca el icono en tu menú de aplicaciones.  
- Pulsa para iniciar y comprobar que funciona.

---

✅ **Consejo:** Si subes nuevas versiones, nómbralas claramente (`miapp-v1.1.apk`, `miapp-v2.apk`) para que tu comunidad sepa cuál es la última.  
⚠️ **Nota:** La APK debe estar firmada para instalarse sin problemas en Android.
