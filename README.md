# Tcae-sas-cadiz-app
# 📚 App TCAE SAS Cádiz

Aplicación Android para la preparación de oposiciones de **Técnico en Cuidados Auxiliares de Enfermería (TCAE)** en el SAS y Diputación de Cádiz.  
Desarrollada y documentada por **@lucompartir-web**, pensada para funcionar en entornos móviles (Termux + Android) y totalmente offline.

---

## ✨ Características principales

- 📝 **Simulacros de examen**: 50 preguntas en 30 minutos, con corrección automática y resumen de fallos.
- 📚 **Banco de preguntas**: Constitución, Estatuto de Autonomía, Biobancos, residuos, instrumental, planos anatómicos, movilización, entorno y constantes vitales.
- 🎴 **Flashcards**: sistema de repetición espaciada para reforzar la memoria.
- ✅ **Checklists prácticos**: guías rápidas para movilización segura, gestión de residuos y toma de constantes.
- 🎨 **Interfaz moderna**: construida con Jetpack Compose y Material Design 3.
- 🔒 **Modo offline**: no requiere conexión a internet, todos los datos están en assets JSON.
- 📱 **APK firmada**: lista para instalar en cualquier dispositivo Android.
