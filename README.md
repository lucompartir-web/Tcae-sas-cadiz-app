# Tcae-sas-cadiz-app

📱 App educativa para preparar oposiciones TCAE SAS Cádiz  
Repositorio de **lucompartir-web**

---

## 📦 Carpeta de APKs

Pulsa para descargar directamente en Android:

- ✅ [`miapp-v1.apk`](https://github.com/lucompartir-web/Tcae-sas-cadiz-app/releases/download/v1/miapp-v1.apk)  
Firmada, modo offline, interfaz moderna con Jetpack Compose

---

## 🚀 Cómo usar

1. 📥 Descarga el APK desde la carpeta `apks/`
2. 📚 Estudia con flashcards para reforzar memoria
3. ✅ Repasa con checklists antes de prácticas o exámenes
4. 🧪 Entrena con simulacros para medir tu nivel y corregir errores
5. 📤 Comparte el repositorio con tu comunidad

---

## ⭐ Características de la app

| Funcionalidad | Descripción |
|---------------|-------------|
| 🧪 Simulacros | 50 preguntas en 30 minutos, revisión de fallos |
| 📚 Flashcards | Visuales, suaves, diseñadas para retención |
| ✅ Checklists | Para repasar antes de prácticas o exámenes |
| 📦 Offline     | No requiere conexión, ideal para estudiar en cualquier momento |
